## Behavior

All CRUD, listing, and error behavior comes from the shared ARM handler (see `docs/resources-2021-04-01-plan.md`). The service file only registers the type and supplies read-only properties:

- `tenantId`: the local default tenant
- `principalId`, `clientId`: UUIDv5 values derived from the lower-cased resource ID, so they stay stable across updates and server restarts

The parent resource group must exist (`ResourceGroupNotFound` otherwise), and deleting the group deletes its identities.

Out of scope for this stage:
- federated identity credentials (`.../userAssignedIdentities/{name}/federatedIdentityCredentials`), a nested child type
- system-assigned identities (`Microsoft.ManagedIdentity/identities/default` on another resource)
- issuing tokens from the instance metadata endpoint
