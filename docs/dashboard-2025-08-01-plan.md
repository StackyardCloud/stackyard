# Azure Managed Grafana (`dashboard-2025-08-01`) Staged Plan

## Objective

Emulate the Azure Managed Grafana control plane (`Microsoft.Dashboard`) on the shared ARM handler (`internal/server/azure_resource_manager.go`): Grafana workspaces with managed private endpoints, integration fabrics and private link resources, and managed dashboards. No Grafana instance runs.

## Behavior

CRUD, listing, cascade and error behavior come from the shared ARM handler (see `docs/resources-2021-04-01-plan.md`). Service-specific rules:

- workspace, dashboard and managed private endpoint names are 2-30 letters, digits or hyphens, starting with a letter and ending with a letter or digit; integration fabric names are 2-20
- `sku.name` is `Essential` or `Standard`, and `sku.size` (`X1` or `X2`) is only for `Standard`
- `publicNetworkAccess`, `zoneRedundancy`, `apiKey`, `deterministicOutboundIP` and `creatorCanAdmin` are `Enabled` or `Disabled`, and `autoGeneratedDomainNameLabelScope` is `TenantReuse`; Azure's defaults are reported when unset
- `grafanaMajorVersion` is `10`, `11` (the default) or `12`, and `grafanaVersion` reports a matching release
- Azure Monitor workspace integrations need `Microsoft.Monitor/accounts` IDs; SMTP needs a `host` and `fromAddress` when enabled, `startTLSPolicy` is checked, and the SMTP `password` is write-only
- the workspace reports a stable HTTPS `endpoint` on host `{name}-{hash}.{location}.grafana.azure.com`, and two stable `outboundIPs` when deterministic outbound IPs are enabled
- managed private endpoints need a target resource ID and, except for private link services, `groupIds`; they stay `Pending`
- integration fabrics need target and data source resource IDs and at least one scenario
- `fetchAvailablePlugins` lists a few plugins, `checkEnterpriseDetails` reports no promotion, and the one private link resource is `grafana`

Out of scope for this stage:
- private endpoint connections to the workspace (listing and approving them)
- Grafana Enterprise marketplace plans, plugin installation and the Grafana data plane
- long-running operation polling: every operation completes synchronously
