# Azure DNS (`dns_2018_05_01`) Staged Plan

## Objective

Emulate Azure DNS Resource Manager REST API (`api-version=2018-05-01`) with deterministic local behavior for:

- DNS zone lifecycle (create/get/list/update/delete)
- DNS record-set lifecycle and record-type scoped listings
- DNS resource reference queries by target resources
- an Azure Go SDK example under `examples/azure/dns-2018-05-01`
- Azure coverage-script wiring for the new service key

- all reviewed methods require `api-version=2018-05-01`

- `zones/delete` explicitly supports `200`, `202`, and `204` outcomes

- claim `Microsoft.Network/dnsZones` and `Microsoft.Network/getDnsResourceReference` route families
- enforce `api-version=2018-05-01` on handled routes
- preserve fallthrough behavior for non-DNS routes

### Stage 2: DNS Zones Core Surface

Implement methods:

- `zones/create-or-update`
- `zones/get`
- `zones/list`
- `zones/list-by-resource-group`
- `zones/update`
- `zones/delete`

Behavior goals:

- deterministic zone resource IDs/types/etag and name-server placeholders
- idempotent delete semantics across `200/202/204` cases
- tag and metadata update merge behavior for PATCH

### Stage 3: Record Sets Surface

Implement methods:

- `record-sets/create-or-update`
- `record-sets/get`
- `record-sets/list-all-by-dns-zone`
- `record-sets/list-by-dns-zone`
- `record-sets/list-by-type`
- `record-sets/update`
- `record-sets/delete`

Behavior goals:

- normalized handling for multiple `recordType` variants (A, AAAA, CNAME, TXT, etc.)
- typed record arrays retained on update responses
- deterministic `fqdn`, `etag`, and parent/child path consistency

### Stage 4: DNS Resource Reference Surface

Implement method:

- `dns-resource-reference/get-by-target-resources`

Behavior goals:

- parse `properties.targetResources` input list
- return deterministic `dnsResourceReferences` results envelope with linked DNS record IDs

### Stage 5: Tests

  - api-version validation
  - positive lifecycle for zone and record-set methods
  - negative paths (missing params, unsupported recordType, unknown zone/recordset)
  - dns-resource-reference body validation and response shape

### Stage 6: Example and Validation

- add `examples/azure/dns-2018-05-01` using Azure Go SDK core pipeline
- include one call per reviewed method with expected status assertions
- verify build and coverage-tool discoverability

Exit criteria:
