# Azure Maps (`maps-2023-06-01`) Staged Plan

## Objective

Emulate the Azure Maps control plane (`Microsoft.Maps/accounts`) on the shared ARM handler (`internal/server/azure_resource_manager.go`): accounts, their keys and account SAS tokens. The Maps data plane (rendering, search, routing) is not served.

## Behavior

CRUD, listing, cascade and error behavior come from the shared ARM handler (see `docs/resources-2021-04-01-plan.md`). Service-specific rules:

- accounts need `sku.name` `G2`, `S0` or `S1`; `kind`, when set, must be `Gen1` or `Gen2`
- `uniqueId` (the client ID for the data plane) is server-owned
- `listKeys` returns stable, URL-safe primary and secondary keys derived from the account
- `listSas` needs `signingKey` (`primaryKey`, `secondaryKey` or `managedIdentity`), `principalId`, `maxRatePerSecond` (1 to 500) and RFC 3339 `start` and `expiry` times with expiry after start; it returns a token of base64 claims signed with the chosen key

Out of scope for this stage:
- the Maps data plane
- `regenerateKey`: the shared handler has no per-resource secret state
- creators (retired), private endpoints, CORS, encryption and linked resources
