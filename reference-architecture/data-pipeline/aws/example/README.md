# Data Pipeline Reference Architecture Example (AWS)

Canonical provider-scoped path for the AWS variant.

This example reuses the existing implementation at:

- `reference-architecture/data-pipeline/example`

## Run

```bash
cd reference-architecture/data-pipeline/aws/example
docker compose up --build
```

Open:

- UI: `http://localhost:8080`
- Backend API: `http://localhost:8081`
